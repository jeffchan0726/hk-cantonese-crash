# 速成練習 — 香港速成輸入法

學同練 **速成輸入法（Sucheng / Quick）**：倉頭頭尾兩碼。

Repo：https://github.com/jeffchan0726/hk-cantonese-crash  
Pages：https://jeffchan0726.github.io/hk-cantonese-crash/

呢個 repo 已經由「廣東話口語速成」改成 **速成輸入法練習器**。

## 功能

- 24 字根鍵盤表（分類、撚完標記已記）
- 拆碼練習：睇字打頭尾碼（常用 / 全部 / 難字）
- 網頁打字：入碼擬字（實體鍵盤都得，1–9 擬候選）
- 查碼：漢字 ↔ 速成／倉頭
- 約 2,200 字，碼表來自倉頭五代（香港用字優先）轉頭尾碼
- 進度存 `localStorage`，唔使登入

## 開 GitHub Pages

1. 開 repo → **Settings** → **Pages**
2. Source 擬 **Deploy from a branch**
3. Branch 擬 **main**，資料夾擬 **/ (root)**
4. Save，等一兩分鐘
5. 用呢條網址：https://jeffchan0726.github.io/hk-cantonese-crash/

本機可以直接開 `index.html`。

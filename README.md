學同練 **速成輸入法（Sucheng / Quick）**：倉頡頭尾兩碼。

Repo：https://github.com/jeffchan0726/hk-cantonese-crash  
Pages：https://jeffchan0726.github.io/hk-cantonese-crash/

## 今次重做參考咗邊啲 app

- **打字練習簿**：貼文練習、打錯兩次先出字根提示
- **倉頡／速成練習工具（cangjie.app）**：限時、書籤、錯字本、課程分段
- **五色打字 AI 平台**：路徑式課程、速度＋準確率追蹤
- **Qwerty Learner**：即時對錯、每日目標

## 功能

- 9 課路徑：字根 → 測驗 → 單碼 → 常用 → 粵語字 → 難字 → 60 秒 → 打招呼文章 → 香港生活文章
- 24 字根鍵盤表（分類、標已記、記憶提示）
- 字根四選一測驗
- 拆碼：常用／粵語／單碼／難字／全部／錯字本／書籤
- 錯一次亮頭碼，錯兩次亮全碼＋倉頡全碼
- 60 秒限時挑戰
- 網頁輸入法：入碼擇字（實體鍵盤 1–9）
- 文章練習：內建香港情景，可貼自訂文
- 錯字本自動收打錯嘅字，打啾會除名
- 查碼：漢字 ↔ 速成／倉頡
- 進度存 `localStorage`，可安裝做 PWA
- 自適應版面：手機底 tab + 螢幕鍵盤；電腦左側選單 + 雙欄 + 實體鍵盤

## 開 GitHub Pages

1. 開 repo → **Settings** → **Pages**
2. Source 擇 **Deploy from a branch**
3. Branch 擇 **main**，資料夾擇 **/ (root)**
4. Save，等一兩分鐘
5. 用呢條網址：https://jeffchan0726.github.io/hk-cantonese-crash/

本機可以直接開 `index.html`。
